```
HWi/

```

To run a homework:

```bash
cd HWi
pip install -r requirements.txt
cd notebook
jupyter notebook          # open Zhu_Chen_HWi.ipynb, then Kernel → Restart & Run All
```

Notebooks load data with relative paths such as `../data/<file>`.
